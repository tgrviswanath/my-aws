AWS Services Used

This project uses three core AWS services to deliver a fast, secure, and cost-effective static website.

🪣

Amazon S3

Stores all static assets (HTML, CSS, JS, images). Static website hosting serves files directly over HTTP.

🌐

CloudFront CDN

Distributes content from 450+ edge locations worldwide. Handles HTTPS, caching, and custom domain support.

🔒

ACM (SSL/TLS)

AWS Certificate Manager provides free SSL certificates for your custom domain, auto-renewed.

🌍

Route 53

DNS management with alias records pointing your custom domain to the CloudFront distribution.

Deploy This Site

Run the deploy script to sync files and invalidate the CloudFront cache.

# 1. Create S3 bucket and enable static website hosting
aws s3 mb s3://your-bucket-name --region us-east-1
aws s3 website s3://your-bucket-name \
  --index-document index.html \
  --error-document error.html

# 2. Deploy using the provided script
./deploy_website.sh your-bucket-name E1ABCDEF123456

# 3. Your site is live at:
# https://<distribution-id>.cloudfront.net
