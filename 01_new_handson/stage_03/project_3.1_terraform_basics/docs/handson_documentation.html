4 Locals Defined

locals {
  name_prefix   = "${var.project}-${var.environment}"          # "handson-dev"
  common_tags   = { Project, Environment, Owner, ManagedBy, CreatedAt = timestamp() }
  is_production = var.environment == "prod"                    # false for dev
  bucket_name   = "${local.name_prefix}-data-${account_id}"   # globally unique
}

6 Key Takeaways — All 5 Phases

Lessons learned across the complete Project 3.1

🔄 Full Lifecycle

init → plan → apply → destroy. Only apply and destroy touch AWS. Always run plan before apply — it's always safe.

📦 Variables = Reusability

One main.tf + different .tfvars = all environments. Validation blocks catch errors before AWS. -var flag overrides .tfvars.

📤 Outputs = Communication

sensitive=true hides values everywhere. -json is the only way to reveal sensitive outputs. -raw removes quotes for scripts.

🔍 Data Sources = No Hardcoding

AMI IDs change — always use data source. Apply with only data sources = 0 resources created. No destroy needed.

🧹 Locals = DRY Principle

Define common_tags once, use everywhere via merge(). Boolean locals control environment behavior. timestamp() auto-tags creation time.

🔒 AWS Security Defaults

AWS auto-applies AES256 encryption to all new S3 buckets since 2023 — even without Terraform config. Always check terraform show.
