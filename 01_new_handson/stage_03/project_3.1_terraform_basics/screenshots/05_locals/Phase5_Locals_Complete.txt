PART A  TOOL THEORY: TERRAFORM LOCALS


A1. What Are Locals?


  Locals are computed values derived from other values.
  They are like variables, but calculated  not passed in.

  Variables  you pass values IN from outside
  Locals     Terraform computes values FROM other values

  locals {
    name_prefix = "${var.project}-${var.environment}"
  }

  Once defined, use anywhere:
    bucket = local.name_prefix
    tags   = local.common_tags


A2. Why Use Locals?


  Problem: DRY (Don't Repeat Yourself)

  Without locals  repeated everywhere:
    resource "aws_s3_bucket" "data" {
      bucket = "handson-dev-data-495331821583"   hardcoded!
      tags = {
        Project     = "handson"
        Environment = "dev"
        Owner       = "vswnth1"
        ManagedBy   = "terraform"
      }
    }
    resource "aws_instance" "web" {
      tags = {
        Project     = "handson"   repeated again!
        Environment = "dev"       repeated again!
        Owner       = "vswnth1"   repeated again!
        ManagedBy   = "terraform" repeated again!
      }
    }

  With locals  defined once, used everywhere:
    locals {
      common_tags = {
        Project     = var.project
        Environment = var.environment
        Owner       = var.owner
        ManagedBy   = "terraform"
      }
    }
    resource "aws_s3_bucket" "data" {
      tags = local.common_tags   one line!
    }
    resource "aws_instance" "web" {
      tags = local.common_tags   same one line!
    }


A3. Locals Syntax


  locals {
    # Simple computed string
    name_prefix = "${var.project}-${var.environment}"

    # Map (tags)
    common_tags = {
      Project     = var.project
      Environment = var.environment
      ManagedBy   = "terraform"
      CreatedAt   = timestamp()
    }

    # Boolean condition
    is_production = var.environment == "prod"

    # Complex expression using data source
    bucket_name = "${local.name_prefix}-data-${data.aws_caller_identity.current.account_id}"
  }

  Rules:
    Locals can reference variables: var.project
    Locals can reference data sources: data.aws_caller_identity.current.account_id
    Locals can reference other locals: local.name_prefix
    Locals CANNOT reference resources (use outputs for that)


A4. Locals vs Variables


  Feature              Variables                    Locals
  
  Keyword              variable                     locals
  Passed in?           YES (from outside)           NO (computed internally)
  Can have default?    YES                          N/A (always computed)
  Can be overridden?   YES (-var, .tfvars)          NO (always computed)
  References others?   NO                           YES (vars, data, other locals)
  Use case             Input parameters             Computed/derived values


A5. Common Local Patterns


  Pattern 1  Consistent naming:
    name_prefix = "${var.project}-${var.environment}"
    Use: bucket = "${local.name_prefix}-data"
         sg_name = "${local.name_prefix}-sg"
         ec2_name = "${local.name_prefix}-web"

  Pattern 2  Common tags (apply to all resources):
    common_tags = {
      Project     = var.project
      Environment = var.environment
      ManagedBy   = "terraform"
      CreatedAt   = timestamp()
    }
    Use: tags = merge(local.common_tags, { Name = "specific-name" })

  Pattern 3  Environment-based conditions:
    is_production = var.environment == "prod"
    Use: status = local.is_production ? "Enabled" : "Suspended"
         instance_type = local.is_production ? "t3.large" : "t3.micro"

  Pattern 4  Account-specific names (globally unique):
    bucket_name = "${local.name_prefix}-${data.aws_caller_identity.current.account_id}"


A6. The timestamp() Function


  timestamp() returns the current UTC time when terraform apply runs.
  Format: 2026-05-13T06:31:55Z

  Use case: Tag resources with when they were created.
    CreatedAt = timestamp()

  Important: timestamp() changes on every apply.
  This causes Terraform to show a "change" on every plan.
  For stable tags, use a fixed string instead.


A7. Common Terraform Commands (Locals Context)


  Command                          Purpose
  
  terraform init                   Download providers
  terraform plan                   See computed local values in outputs
  terraform plan -var="env=prod"   See how locals change for prod
  terraform apply                  Create resources with local values
  terraform show                   See actual tag values including timestamp
  terraform destroy                Clean up resources

PART D  THE main.tf FILE


  File location:
    D:\1.projects\AI\my-aws\01_new_handson\stage_03\
    project_3.1_terraform_basics\05_locals\main.tf

  File contents:

    terraform {
      required_providers {
        aws = { source = "hashicorp/aws", version = "~> 5.0" }
      }
    }

    provider "aws" { region = var.region }

    variable "region"      { default = "ap-south-1" }
    variable "project"     { default = "handson" }
    variable "environment" { default = "dev" }
    variable "owner"       { default = "vswnth1" }

    locals {
      # Local 1: Consistent name prefix
      name_prefix = "${var.project}-${var.environment}"

      # Local 2: Common tags  defined once, used everywhere
      common_tags = {
        Project     = var.project
        Environment = var.environment
        Owner       = var.owner
        ManagedBy   = "terraform"
        CreatedAt   = timestamp()
      }

      # Local 3: Boolean condition
      is_production = var.environment == "prod"

      # Local 4: Complex name using data source
      bucket_name = "${local.name_prefix}-data-${data.aws_caller_identity.current.account_id}"
    }

    data "aws_caller_identity" "current" {}

    resource "aws_s3_bucket" "data" {
      bucket = local.bucket_name
      tags   = merge(local.common_tags, { Name = "${local.name_prefix}-data" })
    }

    resource "aws_s3_bucket_versioning" "data" {
      bucket = aws_s3_bucket.data.id
      versioning_configuration {
        status = local.is_production ? "Enabled" : "Suspended"
      }
    }

    output "name_prefix"   { value = local.name_prefix }
    output "bucket_name"   { value = aws_s3_bucket.data.bucket }
    output "is_production" { value = local.is_production }

Key Concepts Learned


  Locals compute values FROM other values  not passed in from outside
  DRY principle  define common_tags once, use in every resource
  Boolean locals  is_production controls versioning on/off
  timestamp() adds creation time to tags automatically
  merge() combines common_tags with resource-specific tags
  Locals can reference variables, data sources, and other locals
  One variable change  all locals recompute  everything updates
