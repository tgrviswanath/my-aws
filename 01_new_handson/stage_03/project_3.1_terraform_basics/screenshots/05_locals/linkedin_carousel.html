The locals block

4 Locals in main.tf

📄 locals { } block
name_prefix   = "${var.project}-${var.environment}"
# Result: "handson-dev"

bucket_name   = "${local.name_prefix}-data-${data.aws_caller_identity.current.account_id}"
# Result: "handson-dev-data-495331821583"

is_production = var.environment == "prod"
# Result: false (dev) or true (prod)

common_tags   = {
  Project = var.project, Environment = var.environment
  Owner = var.owner, ManagedBy = "terraform"
  CreatedAt = timestamp()  # auto timestamp!
}
📄 Used in resources
bucket = local.bucket_name
tags   = merge(local.common_tags, { Name = "${local.name_prefix}-data" })
status = local.is_production ? "Enabled" : "Suspended"

DRY Principle

Define Once,
Use Everywhere

❌ Without locals — repeated in every resource
resource "aws_s3_bucket" "data" {
  tags = { Project="handson", Environment="dev", Owner="vswnth1" }
}
resource "aws_instance" "web" {
  tags = { Project="handson", Environment="dev", Owner="vswnth1" }  # repeated!
}
Change owner? Update every resource manually. Error-prone.
✓ With locals — defined once, used everywhere
locals { common_tags = { Project=var.project, Owner=var.owner ... } }
resource "aws_s3_bucket" "data" { tags = local.common_tags }
resource "aws_instance" "web"  { tags = local.common_tags }  # same!
Change owner? Update ONE local. All resources updated automatically.

Takeaways

Key Learnings

💡
Locals compute values from variables, data sources, and other locals
💡
DRY principle — define common_tags once, use in every resource
💡
Boolean locals control behavior: is_production ? "Enabled" : "Suspended"
💡
timestamp() auto-adds CreatedAt tag on every apply
💡
merge() combines common_tags with resource-specific tags cleanly
💡
One variable change → all locals recompute → everything updates
