Why Data Sources?

Never Hardcode Again

🔴 Without data source (hardcoded)
ami = "ami-0abcd1234"
Breaks when AWS deprecates the AMI. Different in every region.
🟢 With data source (dynamic)
ami = data.aws_ami.amazon_linux.id
Always the latest AMI. Works in any region. Never breaks.
🔴 Without data source (hardcoded)
bucket = "my-data-495331821583"
Breaks for other team members with different account IDs.
🟢 With data source (dynamic)
bucket = "my-data-${data.aws_caller_identity.current.account_id}"
Works for any account. No hardcoding needed.
