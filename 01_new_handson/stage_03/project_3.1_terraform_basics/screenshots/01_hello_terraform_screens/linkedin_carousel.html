The 5 Commands I Ran

terraform init
Downloads AWS provider plugin locally
❌ No AWS
terraform plan
Previews 3 resources — safe dry run
❌ No AWS
terraform apply
Creates S3 bucket in Mumbai in 5 seconds
✅ AWS
terraform state list
Shows 3 tracked resources in state
❌ No AWS
terraform destroy
Deletes all resources — cost = $0
✅ AWS

Takeaways

Key Learnings

💡
terraform init only downloads plugins — never touches AWS
💡
terraform plan is always safe — always run before apply
💡
Only apply and destroy make real changes in AWS
💡
AWS auto-added AES256 encryption — default security since 2023
💡
State file = Terraform's memory — never edit it manually
💡
Terraform runs locally and talks to AWS via API calls
