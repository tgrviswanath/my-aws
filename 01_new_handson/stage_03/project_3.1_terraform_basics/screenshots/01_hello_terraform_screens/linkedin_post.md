🚀 Day 1 of my AWS + Terraform hands-on journey — and I just provisioned my first cloud infrastructure using code!

Today I completed **Project 3.1 — Hello Terraform** as part of my production-oriented AWS roadmap.

Here's what I did step by step:

✅ Configured AWS CLI with IAM credentials
✅ Installed Terraform v1.7.5 on Windows
✅ Wrote my first `main.tf` — an S3 bucket with versioning
✅ Ran `terraform init` → downloaded AWS provider (v5.100.0)
✅ Ran `terraform plan` → previewed 3 resources before touching AWS
✅ Ran `terraform apply` → S3 bucket live in AWS Mumbai (ap-south-1) in 5 seconds!
✅ Inspected state with `terraform state list` and `terraform show`
✅ Ran `terraform destroy` → cleaned up, cost = $0

💡 Key insight that clicked today:
Terraform runs **locally** on your machine and talks to AWS via API.
Only `apply` and `destroy` actually touch your cloud account.
`init` and `plan` are completely safe — always run plan before apply!

🔧 Tech stack:
→ AWS IAM + S3
→ Terraform v1.7.5
→ AWS CLI v2
→ Region: ap-south-1 (Mumbai)

📌 This is part of my structured AWS roadmap covering:
Cloud Engineering → DevOps → Data Engineering → Platform Engineering

Next up: **Terraform Variables** — making infrastructure configs reusable across dev/qa/prod environments.
