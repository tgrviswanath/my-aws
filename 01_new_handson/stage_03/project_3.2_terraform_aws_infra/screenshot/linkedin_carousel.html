Takeaways

Key Learnings

💡
Terraform is idempotent — re-running apply only creates what is missing
💡
Security groups are chained — each layer only trusts the layer above it
💡
Free tier restrictions — RDS backup_retention_period must be 0
💡
RDS password rules — no @, /, ", or spaces allowed
💡
VPC destroyed last — all resources inside must be gone first
💡
Data source resolved AMI — ami-0999036d4c4235ceb (latest AL2023 in ap-south-1)
