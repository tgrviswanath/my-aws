1 Project Overview

Production-grade multi-tier AWS infrastructure

This project builds a complete production-grade multi-tier AWS infrastructure using Terraform only — no console clicks. It combines everything from Project 3.1 to create a real application stack.

Architecture

Internet | HTTP port 80 ▼ Application Load Balancer (handson-dev-alb) | in 2 Public Subnets (ap-south-1a, ap-south-1b) ▼ Auto Scaling Group (1 EC2 t3.micro running Nginx) | in 2 Private App Subnets | user_data installs Nginx + creates /health endpoint ▼ RDS MySQL 8.0 (db.t3.micro) | in 2 Private DB Subnets | NOT publicly accessible ▼ NAT Gateway | allows EC2 to reach internet for yum updates | in Public Subnet with Elastic IP

4 Bugs Fixed

4 issues resolved before and during apply

BUG 1
Duplicate resources across files

main.tf contained ALL resources AND separate files (vpc.tf, ec2.tf, rds.tf) also had the same resources. Terraform reads all .tf files together — duplicates not allowed.

Fix: Cleared main.tf to contain ONLY the provider block. All resources stay in dedicated files.

Error: Duplicate resource "aws_security_group" configuration on main.tf line 123: resource "aws_security_group" "alb" A aws_security_group resource named "alb" was already declared at ec2.tf:3
BUG 2
Single-line block syntax error

HCL single-line blocks can only have ONE argument. Multiple arguments require multi-line format.

Error: Invalid single-argument block definition ingress { from_port = 80 to_port = 80 protocol = "tcp" cidr_blocks = ["0.0.0.0/0"] } Fix: expanded to multi-line format with each argument on its own line
BUG 3
RDS free tier backup retention limit

Free tier AWS accounts cannot set backup_retention_period > 0 on RDS.

Error: FreeTierRestrictionError: The specified backup retention period exceeds the maximum available to free tier customers. Fix: backup_retention_period = 0 (disables automated backups)
BUG 4
RDS password contains invalid character '@'

RDS passwords cannot contain '/', '@', '"', or spaces.

Error: InvalidParameterValue: The parameter MasterUserPassword is not a valid password. Only printable ASCII characters besides '/', '@', '"', ' ' may be used. Fix: Changed "Handson@2026!" → "Handson2026Pass!" (removed @)

9 Key Takeaways

🔄 Terraform is Idempotent

Re-running apply only creates what is missing. The 27 already-created resources were not recreated on the 3rd attempt.

🆓 Free Tier Restrictions

backup_retention_period must be 0 for RDS on free tier. RDS passwords cannot contain @, /, ", or spaces.

📁 One Resource Per File

Terraform reads all .tf files together. Duplicate resources across files cause init failure. main.tf should contain only the provider block.

🔒 Security Group Chaining

ALB → EC2 → RDS. Each layer only trusts the layer above. RDS is completely unreachable from the internet.

⏱️ Slowest Resources

RDS: 4m33s to create. ASG: 5m42s to destroy (waits for EC2). NAT Gateway: ~2min to create.

🔍 Data Source for AMI

ami-0999036d4c4235ceb resolved automatically — no hardcoded AMI ID. Always use data source for AMIs.
